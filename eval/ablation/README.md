# 对照实验设计（Ablation）

> 单看一套流程的绝对值，无法证明「多 Agent」比「单 Agent」强。Ablation 的核心是**控制变量**：只改一个设计要素，其余不变，在同一批缺陷上比较，从而把「多 Agent 的增量价值」隔离出来。

## 1. 方法论

- **同批缺陷**：所有对照组跑同一份数据集（`swe-bench/dataset/`），消除缺陷难度差异。
- **单变量**：每次只关/开一个设计要素。
- **重复次数**：LLM 输出有随机性，每组合适样本应重复跑 N≥3 次取中位数，或固定 temperature=0 减小方差（需在结果中注明）。
- **判定口径统一**：一律以 `metrics.md` 的 1.2「测试验证修复率」为准，不采信 Agent 自报。

## 2. 对照组设计

### A1：多 Agent vs 单 Agent

| 组 | 配置 | 验证卖点 |
|---|---|---|
| 基线（baseline） | 完整多 Agent 流程（T1+T2+T3+复盘） | — |
| A1a 单 Agent 全流程 | 1 个 Agent 串行完成审查→定位→修复 | 并行提效 + 去偏见 |
| A1b 单 Agent 只修复 | 直接给 issue，1 个 Agent 出 patch | 分阶段流程是否必要 |

**核心指标**：1.2 resolve rate、3.1 wall-clock、1.3 regression rate。

**预期**：若方案成立，baseline 的 resolve rate 应 ≥ A1a/A1b，且 regression rate 更低；wall-clock 因并行更短。

### A2：信息隔离开 vs 关（T3 独立评审）

| 组 | 配置 | 验证卖点 |
|---|---|---|
| 基线 | 评审者只见「缺陷描述 + 目标 + diff」，不见修复推理 | 独立评审去偏见 |
| A2a 隔离开关 | 评审者可见修复者完整推理过程（即同一模型自查） | — |

**核心指标**：2.4 门禁通过率、1.3 regression rate（隔离开关下，是否更容易漏掉回归）。

**预期**：隔离开关组更容易「自查自通过」，回归率上升，从而证明隔离的价值。

### A3：有复盘回灌 vs 无

| 组 | 配置 | 验证卖点 |
|---|---|---|
| 基线 | 复盘 `reusable_rules` 回灌到后续 T1/T2/T3 | 知识沉淀价值 |
| A3a 回灌关闭 | 复盘照常产出，但不注入后续流程 | — |

**核心指标**：4.1 回灌规则命中率、4.2 二次修复耗时下降率、1.2 resolve rate（同类缺陷）。

**预期**：回灌开启时，同类缺陷二次修复更快、命中率更高。

### A4：证据门禁开 vs 关

| 组 | 配置 | 验证卖点 |
|---|---|---|
| 基线 | 假设必须有 `supporting_evidence` + `counter_evidence` + 可复现步骤才允许胜出 | 证据驱动、去幻觉 |
| A4a 门禁关闭 | 允许「无证据断言」胜出 | — |

**核心指标**：2.2 根因定位命中率、1.3 regression rate。

**预期**：门禁关闭时，根因命中率下降（幻觉假设胜出），修复质量下降。

## 3. 样本量与统计显著性

- 每组合适样本量取决于缺陷集大小。方案阶段建议：**每组 ≥10 个缺陷**，难/中/易分层。
- 对 resolve rate 这类二分类结果，报告**置信区间**（如 Wilson 区间）而非只报点估计，避免「小样本修好 8/10 就宣称 80% 修复率」的误导。
- 标注每组的**温度参数、模型、随机种子**，保证可复现。

## 5. 局限与风险

- **软指标主观性**：2.1/2.2 等需要 LLM 判定，需注明判定 prompt 与人工抽检比例。
- **埋点缺失**：3.2 加速比、3.3 成本依赖上游埋点，可能暂时算不出——先以 3.1 wall-clock 和 resolve rate 为主。
- **过拟合**：若缺陷集太小或同质，结论外推性差；需在 `verdict.limitations` 中声明。
